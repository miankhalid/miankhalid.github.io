The Portfolio Journey

Everything we did, why, and how. Timeline from first commit to live site, SEO, and analytics. Open this whenever you wonder "why is it like this?".

Timeline

Each entry = a tagged release + Git commit. Color-coded the Clay way, alternating across the palette.

  • v1.0.0

    Launch: root site build & first deploy

    What

    Built the portfolio from PORTFOLIO-HANDOFF.md: modular site, commit identity Khalid, live at the root user URL.

    Why

    Free hosting, repo must be named miankhalid.github.io, and all content lives in one file: content.js.

    How

    git init + project identity; favicon generated from profile pic (16/32/apple-touch via sips); stripped every em-dash; added dark mode (follows OS + manual sun/moon toggle, remembers via localStorage), removed nav name, hero name bumped 20%; pushed via gh; enabled Pages.

    Learned: gh auto-enables Pages on repo create.
  • v2.0.0

    Liveliness, mobile, Icons, project covers

    What

    Background shapes + parallax, mobile responsiveness, pinned name, Iconify icon system, and real thumbnails for every project.

    Why

    Site felt flat; hero ate the mobile viewport; wanted icons; projects looked text-only.

    How

    CSS blobs + JS parallax (requestAnimationFrame); hamburger mobile nav; brand name in sticky nav; Iconify CDN for all icons; scraped Play/APK app icons, hand-made 5 SVG covers (no dummies).

    Learned: link previews/SEO need OG tags (came later). Personal docs (*.bio.md) accidentally staged → gitignored.
  • v3.0.0

    Parallax fix, scroll-pin name, FAB, polish

    What

    Fixed invisible shapes, single scroll-pinned "Khalid", FAB back-to-top, prominent View button, tech icons, Skills overhaul, better Smash Runner art.

    Why

    Feedback: parallax didn't show; name appeared twice; View looked weak; Skills bland.

    How

    Root cause was a CSS selector mismatch (styled class, HTML used data-shape). One unified scroll handler drives parallax + FAB show + nav reveal.

    Learned: debug by checking selector vs. actual markup.
  • v4.0.0

    Fully randomized parallax + real icons

    What

    Each shape now has its own shape type, size, position, rotation, direction and speed. Real app icons for PicPlayPost & GifDub; Smash Runner uses an Iconify runner glyph.

    Why

    Linear motion felt same-y; app screenshots looked wrong as thumbnails (prefer icons).

    How

    JS buildShapes() assigns a random vx, vy per shape. Icons pulled from store pages + winudf _icon endpoint.

    Learned: store og:image is often a screenshot, not the icon.
  • v5.0.0

    Abstract, theme-aware blobs

    What

    5 large abstract organic blobs (no circles/triangles/squares), blurred, soft radial shade.

    Why

    Feedback: keep it abstract, go big, respect light/dark theme.

    How

    Reads real CSS variables off the active theme via getComputedStyle, converts hex→rgba, random organic border-radius, heavy blur.

    Learned: pulling colors from CSS vars = automatic theme-awareness.
  • v6.0.0

    Multi-platform View links + disabled fallback

    What

    links[] per project → one View button per platform (Google Play / App Store / Web) with a left icon. Projects with no links get a greyed disabled View.

    Why

    Some apps exist on multiple stores; UI should look congruent on every card.

    How

    platformIcon(url) auto-detects icon from the URL host (play.google → Google Play, apps.apple → iOS, else globe).

    Learned: never fabricate URLs; only ship known-good links.
  • v7.0.0

    Masonry project grid

    What

    Project cards no longer equal height, now masonry flow.

    Why

    Cards have very different heights; fixed grid wasted space / looked stiff.

    How

    CSS multi-column masonry (column-width + break-inside:avoid).

    Learned: column-major ordering; a JS variant gives strict L→R order.
  • v8.0.0 / v8.1.0

    Social link previews (OG + Twitter Card)

    What

    Added Open Graph + Twitter Card meta and a branded og-card.jpg (1200×630 landscape).

    Why

    WhatsApp/Slack showed no thumbnail when pasting the link.

    How

    Absolute og:image URL; rasterized an SVG card to JPG with sips (bottle-green brand card).

    Learned: scrapers cache aggressively → cache-bust by appending ?v=; test on opengraph.xyz / FB Sharing Debugger.
  • v9.0.0 → v9.1.0 + current

    SEO, analytics, ownership

    What

    robots.txt, sitemap.xml, JSON-LD Person schema, meta robots + og:locale, Cloudflare Web Analytics beacon, Google Search Console verification tag.

    Why

    Get indexed faster, show structured/rich results, and track visits cookielessly.

    How

    Created SEO files; added standards-track meta; pasted CF beacon token + GSC meta tag. Next: verify in Search Console, submit sitemap, URL-inspection Request Indexing.

    Learned: CF analytics is one script tag; GSC verification is a single meta tag pushed live.

File Structure

Keep this layout. Only content.js is meant to be hand-edited; everything else is build/ops you never touch casually.

miankhalid.github.io/
├── index.html          # shell + all head meta (SEO/OG/analytics). rarely touched
├── styles.css          # all Clay-styled tokens + layouts. rarely touched
├── app.js              # renders content.js → DOM, parallax, nav, icons. never hand-edit casually

├── assets/
