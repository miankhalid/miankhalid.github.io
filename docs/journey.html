    • Google Search Central docs (how crawling/indexing works): https://developers.google.com/search/docs

    1. Created robots.txt at site root: 
      User-agent: *
Allow: /

Sitemap: https://miankhalid.github.io/sitemap.xml
    2. Created sitemap.xml at site root (lists the homepage + lastmod date).
    3. In index.html <head> added:
      • <meta name="robots" content="index, follow, max-image-preview:large">
      • <meta property="og:locale" content="en_US">

    Pre-commit hook: em-dash, syntax, sitemap, personal-doc, journey-log guardrails

    ▾
    What

    Added a real git pre-commit hook (.githooks/pre-commit) that runs on every commit: fails on stray em/en-dashes, fails if node --check fails, fails if any HTML page is missing from sitemap.xml, fails if a personal/gitignored doc is ever staged, and prompts to confirm if a site/config change ships without a matching docs/journey.html update.

    Why

    The v11.1 commit shipped without a journey entry and journey.html had a stale line, both of which AGENTS.md already said not to do; they slipped through anyway because nothing enforced it. Chose a plain git hook over the Python pre-commit framework or a Claude Code hook: this is a zero-dependency static site, adding a framework dependency for 4 shell checks is over-engineering for the project's size.

    Steps
    1. Wrote .githooks/pre-commit: em-dash grep, node --check, sitemap-coverage loop over root + docs/*.html, forbidden-file staged check.
    2. Added an interactive y/N prompt (only when a tty is attached) that fires if the commit touches site/config files but not docs/journey.html.
    3. Wired it up with git config core.hooksPath .githooks so it's tracked in the repo (unlike .git/hooks/, which never syncs) and applies for any future clone.
    4. Tested it directly: confirmed it hard-fails on an injected em-dash + syntax error, and passes clean on a clean staged tree.
    5. Documented the one-time setup command and what each check does in AGENTS.md.
    Check it
    • Hook file: .githooks/pre-commit in the repo
    • Setup command: git config core.hooksPath .githooks
    • Diff: github.com/miankhalid/miankhalid.github.io/commits/main
    Learned: .git/hooks/ is local-only and never travels with the repo; core.hooksPath pointing at a tracked folder is the only way a hook survives a fresh clone without a separate install step.
