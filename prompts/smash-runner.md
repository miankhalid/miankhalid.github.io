# Smash Runner — project thumbnail prompt

Realistic, professional game key-art / marketing screenshot for a portfolio project card. 16:9 crop (480x270 or similar), polished mobile-game aesthetic, NOT a flat abstract vector icon.

**What it is:** Smash Runner, a 2D side-scrolling platform runner game built in Unity3D/C#, multiple levels, character running/jumping mechanics, ads + in-app purchases.

**Visual direction:**
- Realistic in-game screenshot / key-art style render: a stylized 2D side-scrolling platformer scene, viewed as if on a phone screen or as a game marketing banner.
- Foreground: a dynamic cartoon-but-polished runner character mid-jump/sprint over obstacles (gaps, spikes, platforms), motion blur or speed lines behind it to convey momentum.
- Midground: platform tiles, coins/collectibles, a score/coin HUD counter in a top corner.
- Background: a vibrant parallax scene (e.g. a sunset city skyline, forest, or abstract energetic gradient sky) with depth layers.
- Color palette: energetic and vibrant (oranges, teals, or the site's bottle green as an accent in the HUD), high contrast, polished mobile-game marketing quality (think Subway Surfers / Temple Run style promotional art).
- Slight phone-frame mockup optional, or a full-bleed game-screenshot crop without a device frame.

**Avoid:** flat single-color vector shapes, low-res pixel art (unless the actual game is pixel art, which it is not), generic stock photos, cluttered UI, dark/gritty tone.
