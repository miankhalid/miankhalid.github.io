# Leavzy — project thumbnail prompt

Realistic, professional app icon / product shot for a portfolio project card. 16:9 crop (480x270 or similar), clean modern SaaS aesthetic, NOT a flat abstract vector icon.

**Visual direction:**
- Show a realistic laptop or desktop browser mockup displaying a clean HR dashboard UI: a leave-request calendar/timeline, a "days remaining" balance widget, a pending-approval list with avatars, and a sidebar nav.
- Primary brand color: bottle green (#006a4e) as the dominant UI accent (buttons, active nav item, chart bars), on a white/light-gray dashboard background.
- Soft, professional lighting, subtle drop shadow under the device, slight 3/4 perspective angle on the laptop (not flat-on).
- Include small realistic UI details: a calendar grid with a few highlighted "on leave" days, a progress bar for leave balance, a green "Approve" button.
- Style reference: modern SaaS product marketing screenshot (think Notion/Linear/Deel-style dashboard mockups), high production value, soft shadows, rounded 12-16px corner radii on cards.
- No text/logos beyond generic placeholder UI labels (avoid inventing a real company name/wordmark other than a subtle "Leavzy" wordmark in the nav if legible).

**Avoid:** cartoonish icons, flat single-color vector shapes, generic stock-photo people, clutter, low-res look, dark/moody lighting.
